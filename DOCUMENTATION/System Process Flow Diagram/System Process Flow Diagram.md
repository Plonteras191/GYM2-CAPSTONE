4.2-A System Process Flow Diagram

This section presents the system process flow diagram for the Camera-Based Gym Management System for Double Alpha Fitness Gym. The diagram was created based on the information gathered during the requirements gathering phase, which included an interview with the gym owner and observation of the gym's existing manual processes. It shows the complete sequence of activities that the Gym Owner or Admin performs when using the system, from logging in to logging out. The diagram also shows the decisions the system makes at key points, such as checking if the login credentials are correct, determining whether a member's face is recognized, checking membership status, and detecting whether an exercise is being performed correctly.

Figure 4.1. System Process Flow Diagram for the Camera-Based Gym Management System for Double Alpha Fitness Gym.

The flow begins when the admin opens the system and enters their username and password. The system checks if the credentials are correct. If they are not correct, a login error is displayed and the admin is asked to try again. If the credentials are correct, the admin is taken to the Administrator Dashboard where they can choose which module to use.

From the dashboard, the admin can access six modules. In the Member Registration module, the admin enters the member's personal information, contact details, height, weight, and body type, then captures the member's facial photo and saves the complete record. In the Attendance Monitoring module, the camera captures the face of a member entering the gym, and the system checks if it matches a registered member. If the face is recognized, the system records the attendance with the correct date and time. If the face is not recognized, the system displays an alert and no attendance is logged.

In the Program Monitoring module, the admin first selects a member and assigns an exercise from the approved scope. The camera then captures the member's movements. If the exercise is detected correctly, the system counts the repetitions and saves the monitoring results. If the body is not clearly visible or the exercise is not detected, the system prompts the member to reposition in front of the camera. In the Subscription Management module, the system checks whether the member's membership is still active or already expired. If it is active, the membership status is displayed. If it has expired, the admin processes a renewal and the membership record is updated. In the Payment Transaction module, the admin selects the member and the linked membership plan, enters the payment details, selects the payment method — Cash, GCash, or Maya — records the payment, updates the payment history, and activates the membership subscription. In the Reports module, the admin selects the type of report — attendance, membership, program monitoring, or payment — and the system generates and displays the report. After completing the needed tasks, the admin can choose to log out, which ends the session, or return to the dashboard to continue working.

This process flow shows that all major gym operations — from member registration to payment recording — are now handled through a single, organized digital system. Every step that was previously done manually by the gym owner, such as recording attendance in a logbook, checking membership expiration dates by hand, writing payment receipts, and personally watching members exercise, is now replaced by an automated process. The decision points in the flow — such as checking login credentials, verifying a member's face, checking membership status, and detecting exercise movements — show that the system does not simply record data but also checks and verifies information before taking any action.

This system process flow directly addresses the problems identified during requirements gathering at Double Alpha Fitness Gym, including manual attendance recording, delayed membership renewal, inconsistent payment records, and the lack of organized program monitoring. The flow supports the study's general objective of designing and developing a Camera-Based Gym Management System that improves attendance tracking, membership management, program monitoring, and payment recording. Each module shown in the flow corresponds to the functional modules defined in Section 4.1-C and is further detailed in the use case diagrams presented in Section 4.2-D.
